# CAD AI Render Provider Demo

Public-safe demo for the article:

https://erselcakmak.com/articles/adding-ai-render-variations-to-a-cad-application

This sample shows a provider-agnostic shape for generating AI render variations
from a CAD scene capture. It does not call real providers and does not contain
production CAD application code.

## Run

```bash
dotnet run --project src/CadAiRenderProviderDemo
```
