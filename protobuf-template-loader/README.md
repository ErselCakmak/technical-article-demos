# Protobuf Template Loader Demo

Public-safe demo for the article:

https://erselcakmak.com/articles/saving-and-loading-templates-with-protobuf

This sample stores a desktop template as one Protobuf snapshot, saves it through a
small storage abstraction, and loads the last selected template at startup.

## Run

```bash
dotnet run --project src/ProtobufTemplateLoaderDemo
```
